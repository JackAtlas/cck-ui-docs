# CCK UI hooks

[![NPM downloads](https://img.shields.io/npm/dm/%40cck-ui%2Fhooks?style=for-the-badge)](https://www.npmjs.com/package/@cck-ui/hooks)

The [@cck-ui/hooks](https://www.npmjs.com/package/@cck-ui/hooks) package provides some hooks to build custom components. The `@cck-ui/hooks` package is used internally in most other `@cck-ui/*` packages - it is required to be installed in your project to use CCK UI components.

## Installation

```bash
pnpm add @cck-ui/hooks
```

## Usage

The `@cck-ui/hooks` package can be used in any Web Vue application. The package can be used even if you do not use CCK UI components - it is standalone and has no dependencies except Vue.
