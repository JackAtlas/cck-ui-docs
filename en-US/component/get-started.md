# CCK UI Core components

[![NPM Downloads](https://img.shields.io/npm/dm/%40cck-ui%2Fcore?style=for-the-badge)](https://www.npmjs.com/package/@cck-ui/core)

[@cck-ui/core](https://www.npmjs.com/package/@cck-ui/core) package provides essential components: buttons, inputs, modals, typography, and many others. The `@cck-ui/core` package is used internally in most of the other `@cck-ui/*` packages - it is required to be installed in your project to use CCK UI components.

## Installation

```bash
pnpm add @cck-ui/core @cck-ui/hooks
```

## Usage

Follow the [getting started guide](../guides/cck-ui) to learn how to complete the CCK UI setup in your project.
